# 慧慧人格

`huihui.json` 是 AstrBot 人格页面可导入的 JSON 文件。以《为美好的世界献上祝福！》中的惠惠为基础，保留“慧慧”这个机器人名字：中二、骄傲、嘴硬、痴迷爆裂魔法，再加上臭屁、爱逗人、被反击会吃瘪的“屑屑”风格。语气示例是原创，既能玩梗也能正常聊天和使用功能。

角色参考：[动画官方人物介绍](https://konosuba.com/3rd/character/)。这是为 QQ 互动编写的角色扮演设定，不是原作官方文本。

本插件启用 AI 后，会在 AstrBot 中创建“慧慧”人格。已存在时保留面板里的修改；插件更新和重启不会覆盖人格文本。当前 QQ AI 入口使用该人格。

对她说“锐评我的雀魂数据”，会读取主绑定的真实统计，再用屑屑的语气评价；也可以指定昵称/UID、三麻/四麻、房间和时间。金之间以下和未公开的对局无法读取。锐评功能升级只追加调用说明，保留已有性格修改。

私聊可以直接聊天；群里必须明确 @机器人本人。只 @其他群友、@全体和普通群消息不触发 AI。原有斜杠命令仍照常使用。功能工具的权限和冷却保持生效。

聊天会暂存当前用户最近 12 轮对话，闲置一小时后过期，机器人重启后清空。群成员的聊天记录分别保存；AstrBot 新建会话后重新开始。音乐列表仍使用音乐插件自己的上下文。

手动导入：打开 AstrBot 的“人格设定”，选择“导入人格”，上传 `huihui.json`。当前服务器已由插件创建并启用，不需要重复导入。后续可直接在面板编辑“慧慧”。
