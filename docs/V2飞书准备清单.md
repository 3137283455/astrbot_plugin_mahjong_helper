# 群数据 V2：飞书接入准备清单

这是接入前的准备清单。V2 已实现，实际使用与同步规则见 [V2使用说明](V2使用说明.md)。正式封存与新周期切换应在接入测试完成后执行，并留下精确切换时间及封存清单。

## 你需要准备的内容

### 1. 创建企业自建应用

打开 [飞书开发者后台](https://open.feishu.cn/app)，使用你能管理应用和多维表格的同一个飞书团队/组织账号登录。

创建「企业自建应用」，名称可以用「慧慧群数据」。在「凭证与基础信息」保存 App ID 和 App Secret。

在应用能力里添加「机器人」，方便在云文档中添加此应用；实际QQ群消息仍由现有 NapCat + AstrBot 处理。

### 2. 开通权限并发布

在「权限管理」搜索并开通「查看、评论、编辑和管理多维表格」。这项权限用于建立字段和数据表、读取记录、写入及修正记录。不要只开只读权限。

如果控制台按操作细分权限，需包含数据表、字段、视图和记录的读取、新建与更新；具体缺项会由接入检查返回，不需要预先开放整个云盘或通讯录。

在「版本管理与发布」创建版本、提交发布，并由团队管理员完成审核，确认应用已经上线。后续新增权限也需要发布生效。

### 3. 创建空白多维表格

在同一个团队中，新建一份**多维表格**，名称可以用「慧慧群内对局档案」。普通文字文档或传统电子表格不适合直接套用这次的接口。

先保持空白，不用建表头，也不用导入旧数据。数据表、字段、视图由程序按统一结构创建。

初期仅你本人可编辑；其他成员按需设为只读，之后再邀请需要维护数据的管理员。

### 4. 把应用添加到表格

作为表格所有者，打开右上角「…」→「更多」→「添加文档应用」，搜索「慧慧群数据」，授予可编辑权限。不同版本菜单名称可能略有差异。

如果搜不到应用，优先检查：应用与表格是否同一团队、是否已经发布上线、是否开启机器人能力，以及是否已有多维表格API权限。

**应用的API权限和这份表格的访问权限都需要完成。** 仅把文档链接设为可查看，不代表应用可以编辑。

### 5. 准备好后发回这些信息

- 空白多维表格完整链接，优先直接使用 `https://你的团队.feishu.cn/base/...` 形式。
- App ID。
- 告知「应用已发布，已添加为文档应用并授予编辑权限」。

App Secret 保留好，后续直接填到机器人插件配置中，不用发在聊天里。

## 首版同步方式

机器人入库后写入在线表格；表格侧的管理员修改通过定期核对读取，再执行与机器人相同的完整性校验后入库。双向同步不是只导出文件。

初期采用定期核对方案，实际频率按账号API配额、表格规模和服务响应确定，并显示最近成功同步时间、待同步项及异常。当前无需先配置事件回调地址。

后续如果需要更低延迟，再接记录变更通知；不把事件推送配置作为本次准备工作的前提。

## 我来完成的工作

1. 对现有数据库制作一致性备份，生成只读清单；正式切换前再次核对。
2. 加入统计周期，旧周期明细、别名和汇总快照封存，新周期从零开始；旧精华重扫不会自动进入新周期。
3. 继续接收完整终局结算，有人被飞或无人被飞都统计；保持三麻、四麻分离。
4. 创建在线表结构、当前周期/历史/待核对视图；同步身份使用稳定记录ID。
5. 新建、修正和停用对局都经过完整校验；统计数字由对局明细计算，保留修改记录。
6. 验证双方修改、重试、重复通知、冲突、权限和周期隔离，再正式切换。

当前仍只统计本群精华录入样本，不能把未收集的对局也算作真实总战绩。
