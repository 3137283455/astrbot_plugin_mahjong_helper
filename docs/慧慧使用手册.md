# 慧慧功能使用手册

更新：2026.10.28。群聊自然语言请求请@慧慧，私聊直接说；普通命令可直接发。娱乐命令和菜单在群聊也要@慧慧。

## 群数据

被飞几次，谁最惨？看这里。

- `/群数据`
- 三麻、四麻独立总览；不填模式分别显示。
- `/群数据 被飞榜 四麻`
- `/群数据 个人 I咲仡`
- 个人卡片包含被飞次数、被飞率与顺位。
- 还可查：被飞率、一位 / 二位及比率、最高 / 最低。
- `/群数据 最高 四麻　 /群数据 原图 编号`
- 只收本群精华中的完整结算图；文字、牌桌图跳过。
- 被飞＝最终持点＜0；比例仅代表本群精华样本。
- 约2分钟检查新增精华；识别完成才计入，重复去重。
- 首次需群管理员 /群数据 开启；只查询当前群。
- 更多：/群数据 帮助　进度：/群数据 状态

@慧慧 看看本群四麻谁被飞最多

## 雀魂战绩

查数据、看卡片，也可以让慧慧锐评。

- 仅收录金之间及以上的公开对局
- `/雀 玩家昵称 三 铳 30天`
- `/雀 玩家昵称 四 顺 玉 90天`
- 昵称放前面，三 / 四、栏目、房间、时间放后面。
- 后缀参数可换序；默认四麻，无数据再查三麻。
- 栏目：基 / 顺 / 立 / 风 / 和 / 运 / 铳 / 近 / 桌 / 局 / 页
- `/雀 搜 昵称　→　/雀 绑 UID`
- /雀 号 看绑定；/雀 切 UID 换主绑定；/雀 解 UID
- 绑定后可省略昵称，例如：/雀 基。
- 可绑多个公开UID；多人可绑同一UID，不验证归属。
- 筛选：金 / 玉 / 王；7天 / 30天 / 90天 / 365天。
- 近 / 桌 / 局如遇访问验证，会返回玩家网页链接。

@慧慧 锐评一下我的雀魂战绩

## 点歌与歌单

先找已收藏的歌，没有再在线搜索。

- `/搜索歌曲 晴天　　/搜索视频 BV号`
- 出现列表后，5分钟内可续接：播放第二首。
- 也能说：把第二首加入歌单。群聊聊天请@慧慧。
- `/歌单　 /歌单 加 2　 /歌单 播 1`
- 查看 / 收藏搜索结果 / 播放；/歌单 删 1 删除。
- 个人歌单长期保存；/歌单 加 可收藏刚播放的歌。

## B站订阅

订阅当前聊天，更新推送也发到这里。

- `/B站 订阅 UID　　/B站 取消 UID`
- `/B站 列表　　/B站 状态`
- `/B站 测试 UID`
- 重发最新可见动态，可反复查看。
- 过滤示例：/B站 订阅 UID lottery forward
- 上例排除抽奖与转发；UID是B站个人主页的数字。
- 首次需管理员私聊 /bili_login 扫码登录。
- 完整命令、过滤项和提醒设置：/B站

## 友人房广播

房间开好了？一条消息喊人来。

- `/友 房间号或链接`
- 房间内容会原样广播，并@全体成员。
- 可填房间号、链接或其他简短字符串。
- 需机器人为群管理员，且有@全体权限和次数。
- 同一用户：第2次需距上次5分钟；
- 第3次起，每次需距上次15分钟。
- 发送成功后才开始计冷却。
- 这是房间广播；不读取友人房战绩。
