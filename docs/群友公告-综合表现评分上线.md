# 群数据更新：综合表现评分上线

现在可以查群友的综合表现榜了！**S0、S1都支持，三麻和四麻分别排名；不填赛季默认查S1。**

## 怎么算分？

满分100分，**对局成绩占90%，有效场次占10%**。成绩是主要依据，持续参与也有一点优势，场次加成越往后增长越慢。

- **成绩分**：顺位表现占65%，持点表现占35%。
- **顺位表现**：四麻一至四位分别记100、65、35、0分；三麻一至三位记100、50、0分，再取平均。
- **持点表现**：每场用自己的最终持点与同桌平均持点比较，换算为0～100分，再取平均；单场极端高分不会无限拉高评分。
- **场次项**：`10×有效场次÷（有效场次＋20）`，10场约3.33分、20场5分、30场6分，最高接近10分。

**最终综合分＝成绩分×90%＋场次项。** 被飞、最高最低纪录仍可查，但不另外重复加减分。没有和牌率、放铳率等攻防评分。

## 谁能正式入榜？

同一赛季、同一种模式，**满10场有效对局正式入榜**；1～9场显示暂定分，不占正式名次。没有有效评分对局时不显示成0分或50分。

最终分保留两位小数，同分并列，不再用场次破同分。个人档案的昵称右侧也会显示综合评分和综合排名；暂定玩家显示当前场次进度。

## 怎么查询？

```text
/群数据 综合榜 四麻
/群数据 综合榜 三麻 S0
/群数据 个人 清风难胡 三麻 S0
/群数据 评分 清风难胡 三麻 S0
/群数据 评分规则
```

“评分”可以查看顺位分、持点分、场次项和最终分的具体组成。昵称可以只填一部分，再按文字候选回复序号。

**模式、赛季、天数等参数放在后面，顺序可以调换。** 例如 `/群数据 综合榜 S0 三麻` 也可以。群里也可以 @慧慧说：“看看S0三麻综合榜”或“查一下清风难胡S0三麻的综合评分”。

## 哪些对局会计入？

只计算本群已确认的完整雀魂终局结算，并使用标准总持点的对局评分。同图、同一完整结果去重；不能确认、已忽略和不符合评分条件的记录不计入。自定义总持点对局仍可保留普通统计，但不自动混入综合评分。

S1有新结算入库、取消精华或人工修正后，后续查询会按更新后的有效对局计算。S0按封存快照查询，不与S1混排，也不改写历史记录。

**这是本群精华样本的综合表现评分，不是雀魂官方评级，也不代表全部真实战绩。** S0收录偏重被飞对局；今后正常结算也请尽量完整收录，让榜单更有参考价值。
