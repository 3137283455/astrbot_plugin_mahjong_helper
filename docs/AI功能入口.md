# 慧慧聊天与已有功能的 AI 入口

慧慧可以闲聊，也可以使用 AstrBot 原生 LLM Tool 调用现有功能。原生命令与 AI 工具调用同一套业务逻辑。

## 群友怎么用

私聊机器人时，直接说“来道何切题”“给我何切答案”等请求；群聊须 @机器人。两种场景的原生命令都直接由插件执行。

| 消息 | 处理 |
| --- | --- |
| `/何切` 或 `@机器人 /何切` | 原生命令出题，不调用 AI |
| `@机器人 来道何切题`、`@机器人 何且` | AI 调用已有题库出题 |
| `@机器人 给我出5道题` | 一次工具调用，连续出5题 |
| `@机器人 看一下当前何切答案` | 发送当前题的原书答案 |
| `@机器人 何切练习到哪了` | 查看原有练习状态 |
| `@机器人 查一剑风起醉英豪的三麻近30天放铳` | 调用已有雀魂查询，玩家昵称完整保留 |
| `@机器人 搜索雀魂玩家 某昵称` | 调用已有昵称搜索 |
| `@机器人 我绑定了哪些账号` | 显示发起人已有的绑定列表 |
| `@机器人 帮我播放某首歌` | 调用播放器已注册的原生搜索、交付工具 |
| `@机器人 帮我搜一下周杰伦的晴天` | 展示播放器原有选歌列表，再回复序号选歌 |
| 搜歌后说“放第二个”“把第二首加入歌单” | 承接本人刚看到的列表，5分钟内有效 |
| `@机器人 看看今天的老婆`、`@机器人 今天老婆是谁` | 调用娱乐插件已有的“今日老婆” |
| `@机器人 给我功能菜单`、`@机器人 你会什么` | 发送已有的一图流总帮助 |
| `@机器人 给我娱乐菜单`、`@机器人 我要看图片娱乐菜单` | 发送娱乐插件已有的图片菜单，支持分类 |
| 普通群聊、@其他人、单独引用机器人消息 | 不调用 AI |
| `@机器人 你好`、`@机器人 今天打麻将输了` | 慧慧正常聊天，不擅自调用功能 |
| 私聊“你好”“想和你聊会儿” | 慧慧直接回应 |

一次随机出题允许1～5道；批量后当前题为最后一道，其他题可按图片上的题号查看答案。数据查询仍只有金之间及以上公开数据。没有新增排行榜。

## 配置

1. AstrBot 中先配置并测试魔搭官方 OpenAI 兼容服务，记录模型提供商完整 ID。
2. 在本插件开启 `ai_enabled`，将该 ID 填入 `ai_provider_id`。默认不开启，避免影响已有 AI 设置。
3. Agent Runner 选择同一魔搭模型；回退模型列表为空。关闭自动搜索、定时任务、计算机操作、子代理和收费回退。
4. 使用插件创建的「慧慧」人格。也可在“人格设定 → 导入人格”上传 [huihui.json](../personas/huihui.json)。人格文本可在面板编辑，插件重启不会覆盖。允许 `mahjong_quiz`、`mahjong_query`、`bot_menu`、`music_search`、`music_action`、`find_in_bilibili`、`deliver_media`、`query_available_apis`、`call_api_by_name`。播放器和娱乐工具由对应插件提供；未安装或未启用时不会开放，普通闲聊仍可用。
5. 关闭流式回复和随机回复；原生命令仍保留 `/` 前缀。

插件会在处理层核对私聊或群内显式 @机器人、已有命令匹配结果和魔搭服务地址；普通群消息不会进入模型。插件不会安装模型、保存密钥或创建模型回退。

## 实现边界

- `mahjong_quiz`：复用何切出题、原书答案、练习状态及帮助。数量、题号在业务执行前校验。
- `mahjong_query`：复用只读雀魂统计、搜索、绑定列表。结构化参数不会被拼成任意命令执行。
- 播放器沿用其现有工具及选歌权限、会话、下载规则。
- 搜歌、放歌先查发起人有权使用的歌单，命中直接复用已保存的具体视频分P；未命中才在线搜索。加入歌单只保存本人所选项目，不重新猜歌名。
- 音乐列表上下文按会话和用户保存5分钟；聊天模型不需要继承整段群聊。查看新列表会替换当前编号，加入歌曲不会改变刚显示的列表编号。
- 雀魂查询不指定三/四时先查四麻，确实无数据才查三麻；卡片标题按实际返回模式显示。明确指定模式不自动切换，接口报错也不会被当成“没有数据”。
- 娱乐沿用 API 聚合插件的查询和执行工具，保留启用状态、作用域与权限检查。模型只看到当前用户可用的功能名称、类型、参数名，不包含接口地址或密钥。文字结果直接转发，图片等媒体保留原来的发送方式。
- `bot_menu` 直接复用已有总帮助、娱乐分类、雀魂和何切菜单；“你会什么”“怎么用”也属于功能请求。
- 管理配置、订阅变更、重置、绑定修改和 @全体广播继续由原生命令处理，不向 AI 暴露。
- 普通闲聊直接发送模型回复。聊天上下文按群/私聊、用户和 AstrBot 会话分别保存，最多暂存最近12轮，闲置一小时或插件重启后清空，新建会话重新开始；不混入其他成员的记录。
- 功能工具直接发送真实结果，完成后抑制额外预告和重复确认。
- 终结工具执行后移除本次请求的工具，防止模型同一轮重复执行；重复平台消息还会在5分钟内去重。
- 使用 AstrBot 4.28.1 的原生钩子和工具，无自建命令扫描器或模型路由。
- 模型失败时返回原生命令提示，原生命令不依赖 AI 服务。

免费额度及计费规则由魔搭账户和所选模型决定。代码固定已批准的模型来源，不会自行切换到其他服务；部署时还需将 AstrBot 的回退列表设为空。
