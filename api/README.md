# 本地雀魂 API 程序放置目录

程序不随本仓库再分发，请从上游项目的正式 Release 下载：

https://github.com/Xcheng-dada/Majsoul-Plugin/releases/latest

解压后只需把当前平台对应的程序放在本目录：

- Windows：`Majsoul.ProtocolLogin.Api-win-x64.exe`
- Linux：`Majsoul.ProtocolLogin.Api-linux-x64`

Linux 还需为程序赋予执行权限。插件默认检测 `127.0.0.1:5088`；没有已运行实例
时，会自动启动这里的程序。
