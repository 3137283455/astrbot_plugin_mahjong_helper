# bili播放器

面向 AstrBot 的 Bilibili 点播插件：从 Bilibili 搜索并锁定具体分 P，按意图发送视频、可播放音频或音频文件；平台不适配时自动改发文件。

## 功能

- **自然语言点播**：`我要听晴天`、`我要看晴天`。LLM 提取条件，只允许从插件当次返回的候选中选择。
- **显式搜索**：`搜索歌曲 <关键词>` / `搜索视频 <关键词>`，展示最多 10 条候选，用户回复序号交付。
- **精确视频**：识别 AV/BV 号与 `bilibili.com/video/...` 链接，列出全部分 P；`b23.tv` 暂不支持。
- **可选登录**：匿名即可搜索播放；登录仅用于提升受限内容可用性。

## 安装

1. 安装 `ffmpeg`，确保在 AstrBot 进程的 `PATH` 中。
2. 可选：`python -m pip install "qrcode[pil]"`，用于 WebUI 扫码登录。
3. 在 AstrBot 插件仓库中填入：

```text
https://github.com/57Darling02/astrbot_plugin_bili_player
```

运行要求：AstrBot `>=4.26,<5`、Python `>=3.10`、可访问 Bilibili。自然语言点播需要模型支持工具调用；建议 Provider 工具超时直听 ≥ 300 秒、直接视频 ≥ 900 秒。

## 使用

直接说意图：

```text
我要听周杰伦的晴天     # 发送可播放音频
我要看晴天             # 发送视频
下载晴天               # 展示候选，确认后下载音频文件
```

或者显式搜索，再回复序号：

```text
搜索歌曲 晴天
1          # 发送第 1 项的视频
1 音频     # 播放第 1 项
1 音频下载 # 下载第 1 项
取消       # 结束选择
```

精确视频会列出全部可交付分 P：

```text
搜索视频 BV1xxxxxxxxxx
搜索歌曲 https://www.bilibili.com/video/BV1xxxxxxxxxx/
```

## 交付边界

| 意图 | 交付 | 限制 |
| --- | --- | --- |
| 听 / 播放 | 语音 | ≤ 15 分钟、25 MiB；超限或平台不支持时改发文件 |
| 看视频 / 未明确 | 视频 | ≤ 150 MiB；平台不支持时改发文件 |
| 下载音频 | 音频文件 | ≤ 100 MiB、不限时长；必须用户确认 |

候选只显示标题和时长；超过 15 分钟的音频标记“音频仅可下载”。`weixin_oc` 平台的语音会直接以文件交付。

## 管理与安全

WebUI 的“bili播放器”页面仅 Dashboard 主账号可访问：

- 查看 `ffmpeg` 健康状态。
- Bilibili 扫码登录、取消或退出；退出只删除本地凭证。
- Cookie 只存插件数据目录 `accounts.json`（`0600`），不进入聊天、日志或 WebUI。
- 媒体文件发送后立即删除；无播放历史、收藏和缓存。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 提示缺少 ffmpeg | `ffmpeg -version`，确认 PATH |
| 无法生成二维码 | 安装 `qrcode[pil]`，检查网络和管理员权限 |
| 能搜索不能发送 | 检查 ffmpeg、适配器文件上限、Bilibili 播放权限 |
| WebUI 不提示更新 | 确认从仓库安装，且 `metadata.yaml.version` 已递增 |
