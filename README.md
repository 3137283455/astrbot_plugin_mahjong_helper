# 日麻助手 AstrBot 插件

面向群友的图文使用说明见[机器人使用手册](docs/机器人功能手册.md)；聊天中发送 `/help` 或 `/帮助` 可直接查看一图帮助。

一个可直接安装的 AstrBot 插件，合并了 601 道何切题和雀魂玩家工具。已移除
抽卡、货币、签到、商店等经济系统。

## 功能

- 601 道何切题：随机不重复、指定题号、原书答案、每日自动出题；发送前自动生成高清 PNG 缓存。
- 雀魂账号：昵称搜索、UID 绑定、多账号与主账号切换。
- 战绩：基本、顺位、立直、牌风、和铳、血统等高清 PNG 卡片；支持快捷命令、文字版、四麻/三麻、房间和时间筛选。
- 菜单：`/雀` 快捷菜单、`/雀 帮` 或 `/何切 帮` 完整帮助默认发送分类卡片，普通用户和管理员看到的内容不同。
- 对局：最近牌谱链接与名次结果。
- 订阅：按群或私聊会话自动播报新对局。
- 友人房广播：群内 `/友 房间号或链接`，机器人 @全体发送房间信息；按发送者限制频率。
- 可选慧慧 AI：私聊可闲聊，群内 @机器人后可聊天或自然语言调用已有功能。支持何切、雀魂查询、娱乐、音乐搜索与播放。人格导入文件见 [慧慧人格](personas/huihui.json)，配置见 [AI 入口说明](docs/AI功能入口.md)。
- 雀魂数据锐评：说“锐评我的雀魂数据”或“锐评某昵称的三麻近30天”，慧慧会读取真实公开统计，结合顺位、和牌、放铳等指标吐槽并给建议。未指定玩家查本人主绑定；仅覆盖金之间及以上公开数据。
- 何切题库已对照原书全量校验，补齐跨页和缺失解析，保留原有题号与进度。详见 [601题校验结果](docs/何切题库全量校验.md)。

## 安装

在 AstrBot 插件市场的“通过 GitHub 仓库安装”中填写：

```text
https://github.com/3137283455/astrbot_plugin_mahjong_helper
```

也可以将仓库目录放入 AstrBot 的 `data/plugins/`，然后在 WebUI 重载插件。
运行数据默认保存在
`data/plugin_data/astrbot_plugin_mahjong_helper/mahjong_helper.db`。

本仓库如设为私有，需要在运行 AstrBot 的机器上配置有权访问该仓库的 GitHub
凭据；也可以下载 Release 压缩包后手动安装。

## 首次配置

雀魂搜索和玩家统计通过牌谱屋公开接口读取，默认不需要 Token。牌谱屋只收录
金之间及以上的公开段位场数据，因此低段位玩家或未参加对应场次的玩家可能搜不到。

牌谱屋网页遇到对局接口的 `x-cap-token-required` 限制时，会自动完成 CAP 验证，
获取临时令牌后重试。插件目前没有这个验证流程，因此 `/雀 局`、`/雀 近`、
`/雀 桌` 在接口触发验证时会返回玩家页链接，供用户自行在浏览器中查看；对局
订阅仍需接口授权。尚未找到公开的固定 API 密钥申请入口；
如需机器人长期接入，可在[牌谱屋项目 Issue](https://github.com/SAPikachu/amae-koromo/issues)
向维护者说明用途、预计请求频率，并询问允许的接入方式。只有在维护者明确提供
可用于机器人的 API 凭据后，才在 AstrBot 配置页填写 `koromo_token`，或由管理员
**私聊**机器人：

```text
/设置牌谱屋Token 你的Token
```

不要在群聊中发送 Token，也不要把网页临时 CAP 令牌当作长期密钥。
何切功能不依赖任何外部接口，题库已经内置，无需另外整理。

## 常用命令

- `/雀 帮` 或 `/何切 帮`：按当前用户权限显示功能卡片；需要复制命令时使用 `/雀 帮 文` 或 `/何切 文`。旧命令 `/雀魂帮助` 仍可使用。AstrBot 自带 `/help` 负责显示全局命令列表。

### 何切

- `/何切`：随机出题，本轮 601 题不重复。
- `/何切 帮`：查看图片帮助。
- `/何切 123`：显示指定题号。
- `/何切答案` 或 `/何切答案 123`：查看原书答案。
- `/何切状态`：查看进度。
- `/何切自动 开启 19:30`：管理员开启当前会话每日出题。
- `/何切自动 关闭`：关闭每日出题。

题图默认以 2 倍尺寸转为 PNG 并轻度锐化，以减少 QQ 二次压缩导致的模糊。首次打开
某道题时生成缓存，后续直接复用；可在插件配置中通过 `enhance_images` 关闭，或用
`image_scale` 设置 2～4 倍放大。

### 友人房广播

- `/友 房间号或链接`：仅在 QQ 群使用。发送前检查机器人是否为群主或管理员、能否 @全体及剩余次数；发送后核对 QQ 消息中的 @全体和次数消耗。第一次可立即发送；第二次须距上次至少 5 分钟，第三次及以后每次须距上次至少 15 分钟。冷却按 QQ 用户跨群计算并在重启后保留；无法确认 @全体成功时不计入冷却。

### 玩家与战绩

- `/雀 搜 玩家名`：搜索 UID；`/雀 绑 UID`：保存常用查询对象；`/雀 号`：查看已保存的 UID。
- `/雀 切 UID`：切换默认查询对象；`/雀 解 UID`：删除一个；`/雀 解 全部`：清空。

“绑定”只是按发送命令的 QQ 用户保存牌谱屋公开 UID，跨群共用，方便省略查询参数；它不登录雀魂，也不验证账号归属。只能保存牌谱屋已收录金之间及以上公开数据的 UID，三麻、四麻任一有数据即可。首次保存的 UID 成为默认查询对象，再保存其他 UID 不改变默认对象。旧版曾允许保存无公开数据的 UID；这类记录仍保留，可用 `/雀 号` 查看并自行删除。
- `/雀`：快捷菜单卡片；`/雀 帮` 显示完整图片帮助；`/雀 文` 显示可复制的文字菜单；`/雀 [UID或昵称]`：基本卡片。
- `/雀 基` 基本、`/雀 顺` 顺位、`/雀 立` 立直、`/雀 风` 牌风、`/雀 和` 和铳、`/雀 运` 血统：默认发送高清 PNG 卡片。
- `/雀 铳` 最近大铳、`/雀 近` 趋势、`/雀 桌` 同桌、`/雀 局` 对局。
- `/雀 页 [UID或昵称]`：直接发送对应玩家的牌谱屋页面链接。

推荐格式：`/雀 [UID或昵称] [三/四] [栏目] [房间] [时间] [文]`。昵称写在前面，
可以包含空格；后面的参数顺序不限。栏目包括`基`、`顺`、`立`、`风`、`和`、
`运`、`铳`、`近`、`桌`、`局`、`页`；房间可写`金`、`玉`、`王`，时间可写
`7天`、`30天`、`90天`、`365天`。例如`/雀 一剑风起醉英豪 三 铳 30天`、
`/雀 12105509 30天 玉 立 四`、`/雀 12105509 三 局 2`。
不填写玩家时使用已保存的默认查询 UID；旧的`/雀 立 12105509 玉 30天`写法继续可用。
想复制数据时，在末尾加 `文`，例如 `/雀 立 文`。完整写法 `/雀魂 立直 ...` 和
旧的 `/雀魂查询`、`/查询三麻`、`/雀魂对局` 等命令继续可用。
卡片使用服务器中文字体绘制 PNG，文字和图表在 QQ 中仍可缩放查看。
这些栏目取自 [牌谱屋玩家页](https://amae-koromo.sapk.ch/player/12105509/9/)
及其 [开源前端](https://github.com/SAPikachu/amae-koromo)。

牌谱屋目前可能对机器人访问对局列表返回 `x-cap-token-required`。这时“对局、趋势、
同桌”以及旧版最近对局命令会给出对应玩家的网页链接，用户可在自己的浏览器里查看；
配置获准使用的 API 凭据后仍会尝试直接查询。“基本、顺位、立直、更多、和铳、
血统、大铳”仍可从公开统计接口查询。网页链接只供手动查看，不能用于自动订阅。

### 自动订阅

- `/雀魂订阅 UID或昵称`、`/三麻订阅 UID或昵称`
- `/雀魂订阅状态`、`/三麻订阅状态`
- `/开启雀魂订阅 玩家`、`/关闭雀魂订阅 玩家`、`/删除雀魂订阅 玩家`
- 三麻对应命令为 `/开启三麻订阅`、`/关闭三麻订阅`、`/删除三麻订阅`

订阅管理只允许 AstrBot 管理员执行。首次订阅只记录当前最新牌谱，之后才播报
新对局，避免一次发送全部历史记录。

## 权限与凭据

- 普通用户可以使用何切、玩家绑定、玩家查询、战绩卡片和查看订阅状态；已配置牌谱屋密钥时也可查询对局。
- 何切重置、每日自动出题、订阅管理、设置可选牌谱屋 Token
  只允许 AstrBot 管理员执行。
- 可选牌谱屋 Token 只能在私聊中提交。
- AstrBot 管理员需要在 AstrBot 配置中的管理员 ID 列表里填写自己的 QQ 号。

## 慧慧一图帮助

`/help`、`/帮助` 与 AI 的总功能菜单共用 [高清帮助图](data/help_one_page.png)。2026-10-27 更新为黑橙配色，补齐群数据、B站订阅、歌单优先搜索和列表续接、友人房冷却，以及当前76项娱乐项目。完整文字版见 [慧慧使用手册](docs/慧慧使用手册.md)。

帮助图与文字手册由同一内容生成，娱乐目录只保留项目名称，不包含接口地址或凭据。维护时在插件目录执行：

```bash
python tools/build_user_help.py
# 从已安装娱乐插件的实际项目池刷新公共目录：
python tools/build_user_help.py --pool ../astrbot_plugin_apis/presets/api_pool_default.json
```

生成器检查文字宽度、模块高度和画布边界。替换 `data/help_one_page.png` 即可更新菜单图。


## 符数速查

发送 `/符数`，按顺序返回两张原图：符数速算规则、四麻番数×符数×点数对照表。群聊、私聊均可使用，无需额外配置。也可私聊或@慧慧请求“看看符数表”，通过现有菜单工具发送同样的两张图。图片由用户提供，保持原始文件内容。

雀魂官网：`/雀魂官网` 直接发送 https://www.maj-soul.net/ 。也可私聊或群聊 @慧慧索要雀魂官网链接。
