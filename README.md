# 慧慧优惠雷达

AstrBot 独立插件，通过本机 PerkRadar API 查询优惠线索并生成图片卡片与原文链接。

依赖上游：[luobinger/PerkRadar](https://github.com/luobinger/PerkRadar)。保留上游授权与来源标识，线索不等于已核实可领取。

## 使用

- `/优惠`、`/优惠 Epic`、`/优惠 游戏`：查询并发送卡片与链接的合并转发。
- `/优惠 搜索 云服务器`：按标题搜索。
- `/优惠 第2页`、`/优惠 下一页`：沿用本人当前会话最近十分钟的筛选。
- `/优惠 帮助`、`/优惠 状态`：图片菜单及来源状态。
- `/优惠 订阅 游戏`、`/优惠 取消订阅 游戏`：当前会话订阅管理；取消不带参数则全取消。
- `/优惠 刷新`：管理员后台抓取；其他命令可正常使用。

群主、群管理员及 AstrBot 管理员可以管理订阅和手动刷新。默认没有订阅，不向群发送部署消息或历史条目。重启重新建立当前基线，不追发停机期间线索。推送不艾特全体，失败只有限重试原合并转发，不降级为文字。

## 配置与运行

插件默认读取 `/bot/perkradar/deploy/client.json` 中的本机服务 URL 和令牌。凭据文件应限制读权限，不提交 GitHub。服务仅回环监听，不需要开放公网端口。

机器人查询只读已抓取数据；上游正常约两小时抓取一次，插件只在存在订阅时每60秒检查本地列表。来源失败、空结果、数据过时分别处理。首次完整数据尚未就绪时使用 `/优惠 状态` 检查。

AI 工具为 `perkradar_query`、`perkradar_manage`。在现有慧慧助手中已通过工具白名单接入；群聊必须明确艾特机器人，私聊可以直接说。安装到其他机器人时需按该机器人的工具范围配置。

## 更新

AstrBot 中更新本插件只更新适配层，不自动升级上游服务。上游使用锁定提交与独立持久数据，升级前跑测试、备份数据库并保留上一版本。上线不改变订阅和已发送基线，回滚涉及数据库迁移时需恢复匹配的升级前数据库。部署提供管理脚本和维护说明，普通群命令不会执行任意代码或升级服务。
