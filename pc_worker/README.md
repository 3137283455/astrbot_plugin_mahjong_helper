# Mortal 4.1b 电脑工作端

电脑只负责专用浏览器提交和取报告，分析由官方 Mortal 4.1b 服务完成。不会改用其他模型，不安装模型权重，不需要GPU。

服务器保留队列、报告和QQ通知。电脑主动建立经过主机密钥校验的SSH连接，网关只监听服务器本机；电脑的浏览器控制端口只在本机使用，不经过隧道公开。专用SSH账号只允许指定的转发，不授予服务器命令执行权限。

`private/config.json`、SSH私钥、浏览器配置、正在处理的任务和待回传报告属于本机私有运行数据，不提交GitHub。工作端中断后会恢复已保存的任务号；已生成报告先保存在本机，连接恢复后再回传。服务器对任务结果去重，过期租约不能覆盖新任务。

电脑关机、断网、休眠期间，任务保留在服务器，其他机器人功能照常运行。遇到站点验证，浏览器等待管理员正常完成验证，不自动解题或点击验证码。验证通过后继续原任务，无需群友重发。

开机自启使用当前Windows用户的登录触发任务；浏览器需要交互桌面，因此须登录Windows后才能工作，不是在尚未登录时运行。独立看护程序会在工作进程退出后自动拉起它；任务计划负责登录启动和看护程序本身的失败重启，网络断开则由工作端自动重连。请不要让电脑自动休眠。

默认安装目录下的 `status.json` 可查看在线状态、当前任务和更新时间，`logs/worker.log` 为轮转日志。`install_windows.ps1` 注册登录自启；通过Windows任务计划程序可停止或取消自启。

安装目录内提供“查看状态.cmd”“启动工作端.cmd”“停止工作端.cmd”。停止只影响电脑工作端，不关闭机器人；下次登录仍会启动。要取消自启，在任务计划程序中禁用“Mortal4.1b电脑工作端”。

提交后恰好崩溃且未能保存任务号时，不冒险自动重复提交，会提示检查并重试。模型一致率只是与该模型的决策吻合程度，不等于实战胜率。
